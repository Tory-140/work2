# work2 ##Студент:## [Мовенко Вікторія Віталіївна] ##Група:## 6.І10.25-ср ##Питання для самоконтролю
1. **Які основні обов’язкові теги входять до структури HTML-документа?**
   
   < html> < head> < body> < title> < h1> до < h6> 
   
2. **Для чого використовується тег <head> і які елементи можна в ньому розміщувати?**
   Призначений для зберігання інших елементів, мета яких - допомогти браузеру в роботі з даними. Також всередині контейнера <head> можуть знаходитися мета-теги, які використовуються для зберігання інформації призначеної для браузерів і пошукових систем, назву документа, скрипти, стилі і багато іншого.
   
3. **Яке призначення тега < title>?**
   Відображає у заголовку браузера ім'я поточного html-документа. Він - обов'язковий тег і має бути присутнім на кожній веб-сторінці. Він повинен бути розташований всередині контейнера head.
   
4. ** Яка різниця між тегами < head> та < body>?**
   <head> - містить службову інформацію, налаштування та підключення ресурсів, невидимих для користувача на самій сторінці. <body> ж містить увесь контент, який безпосередньо виводиться у вікні браузера та з яким взаємодіє користувач (тексти, картинки, таблиці, форми, меню).
   
6. **Для чого використовують заголовки < h1>–< h6> і яка між ними відмінність?**
    Визначає заголовки різного рівня на веб-сторінці. < h1> — найголовніший заголовок першого рівня, а < h6> — заголовок найнижчого, шостого рівня.
   
7. **Як створити абзац тексту в HTML-документі?**
   Для створення абзацу використовують парний тег < p>
   
8. **Яким тегом вставляють гіперпосилання на іншу сторінку чи сайт?**
   HTML теґ < a> створює посилання на іншу сторіку(Зовнішне посилання) або на певний елемент цієї сторінки.

9. **Що таке абсолютне та відносне посилання? Наведіть приклади.**
   Абсолютне посилання - містить повну адресу ресурсу, включаючи протокол (https://) та доменне ім'я. Використовується для переходу на сторонні сайти.
   Наприклад: <a href="https://moodle.znu.edu.ua/message/notificationpreferences.php" (знайшла досліджуючи)
   Відносне посилання - вказує шлях відносно поточного файлу або сайту. Використовується для зв'язку сторінок усередині власного проєкту.
   <h3><a href="/cms/index.php?action=news/view&start=0&site_id=27&lang=ukr">Новини</a>
     
10. **Як створити внутрішнє посилання (якір) на певний фрагмент сторінки?**
   Для створення якоря зробити закладку в відповідному місці і дати їй ім'я за допомогою атрибута name тега <a>. Як значення href для переходу до цього якоря використовується ім'я закладки з символом решітки (#) спереду. Між тегами <a name="top"> і </a> текст не обов'язковий, так як потрібно лише вказати місце розташування переходу за посиланням, що знаходиться внизу сторінки. Ім'я посилання в якорі починається з символу #, після чого йде ім'я якоря, воно вибирається будь-яке, відповідне до тематики. Головне, щоб значення атрибутів name і href співпадали (символ решітки не береться до уваги).

11. **Який атрибут тега < a> задає адресу переходу?**
   Адресу переходу задає атрибут href, який, власне, і вказує місце, куди буде посилатися створене посилання.

12. **Який тег застосовують для вставки зображення і які основні атрибути він має?**
    Теґ <img> призначений для відображення зображення на Web-сторінці. Має два обов'язкові атрибути атрибути: src використовується для завантаження зображення, а саме вказує шлях до зображення від файлу HTML.
alt задає альтернативний текст для випадку, коли картинка не завантажилась або у клієнта є обмеження на обсяг завантаженн.

13. **Як створити просте меню навігації між сторінками за допомогою списків?**
    HTML теґ <nav>, визначає, групу посилань, що є навігацією по сайту. Такі посилання зазвичай ведуть на інший розділ, головну сторінку, контакти і інше.
    Маркованого списку <ul>, елементів списку <li> та посилань <a>
    
14. **Яким тегом підключається favicon-іконка сайту?**
    Іконка сайту підключається усередині тега <head> за допомогою тега <link> зі спеціальними атрибутами.
    
15. **Що відображається у браузері, якщо вказати некоректний шлях до ресурсу (зображення, сторінки, favicon)?**
    Якщо вказати некоректний шлях до ресурсу зображення, браузер не зможе знайти файл і покаже порожню рамку зі значком «битої картинки». Якщо сторінки то при кліку на таке посилання браузер видасть стандартну помилку сервера або систему «404 Not Found». А якщо favicon браузер просто проігнорує підключення і відобразить стандартну пусту вкладку без іконки.
